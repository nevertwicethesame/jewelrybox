# Never Twice the Same

A personal catalog for an antique and vintage jewelry collection. It runs as a single web page with no server, accounts, or build step, and is designed to be added to an iPhone Home Screen.

Live site: https://nevertwicethesame.github.io/jewelrybox/

## Features

- **Catalog:** record each piece with its title, category, period, era, country, maker, stones, metals, motifs, colour, hallmarks, ring size, measurements, and notes.
- **Photos:** a shared gallery holds reference screenshots, comparables, and cover photos. A cover can be cropped to a square thumbnail.
- **Link to Record:** attach gallery images to a piece as references, comparables, or covers.
- **Wishlist:** save wanted items with a photo, a link, and a type. Reorder the grid by dragging.
- **Secret Compartment:** a keyword-protected section.
- **Dashboard:** summary figures across the collection.
- **Jewelry of the Day:** a random pick weighted toward pieces not worn recently.
- **Quick add:** paste a listing's details, generated by Claude from screenshots, into a piece.
- **Import and export:** CSV for spreadsheet-style editing, and JSON for full backups that include photos, the wishlist, and settings.
- **Backup reminder:** a banner appears when the last JSON backup is more than 7 days old.
- **Update notice:** a banner appears when a newer version is published.

## Install on iPhone

1. Open the live site in Safari.
2. Tap Share, then **Add to Home Screen**.
3. Open the app from the Home Screen icon. Data is kept on that device, so use the Home Screen icon consistently.

## Your data

All data is stored on your device in the browser's IndexedDB storage. Nothing is uploaded to a server.

Browser storage can be cleared by iOS in some situations, so keep regular JSON backups:

1. Open the menu and choose **Export JSON**.
2. Save the files to Files or iCloud Drive.

To restore, open the menu and choose **Import JSON**, then select the backup files. Restoring replaces the data on the device, and the app asks you to confirm first.

## Privacy

- The app has no accounts, analytics, or tracking, and it loads no outside scripts, fonts, or stylesheets.
- Your collection, photos, and wishlist stay on your device. The only request the app makes is a check for `version.json` on this site, to show the update notice.
- Wishlist links open in a preview frame or a new tab. The sites you visit see a normal request from your browser.
- GitHub Pages, which hosts the site, may log visits as any website does.
- JSON backups are not encrypted. Anyone who can open a backup file can read it, so store backups somewhere private.
- Quick add only sends a screenshot to Claude when you choose to send it yourself, outside the app.

## Versioning

The version is set in `APP_VERSION` in `index.html`. Update `version.json` to the same number when a release changes the app, so installed copies show the update notice.

## Development notes

- There is no build step. Edit `index.html` and publish it.
- Check the script before publishing, for example by extracting the `<script>` block and running `node --check` on it.
- The app has no test suite in this repository.
